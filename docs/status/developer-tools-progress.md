Role: developer-tools. Scope is the ten modules in implementation-ownership.md. No peer edits, alternate source inputs, reference binaries, corpus inputs, subagents or publication.

## Supported implementation and evidence

- **Bindings_Generator:** reviewed option defaults, thematic declaration/type records, native model dependencies, target parameter, exact name/replacement arrays, literal converters, include-path discovery, validation and both generate_bindings overloads. A source-built private libclang C backend parses one C header, emits named native functions/records/unions/typedefs/enums/arrays/callbacks and layout assertions, strips common enum prefixes with original aliases, preserves attached documentation and honors supported output controls. Actual public fixtures call generated native bindings, verify mutations/callbacks/named arguments, use official SDK stdint typedefs, and prove malformed-input failure preserves existing files. This uses installed official libclang 23 as a staged dependency; the reviewed public version constant remains 21. Full public traversal/bridge/native reexport/helper support is pending.
- **Generate_C_Header:** all public fields/entry points, reflected dependency ordering, type-name collision suffixes, C11 normal enums, C23 fixed-underlying enums, uppercase-derived enum prefixes, C/C++ linkage/preamble, opaque procedure values and discovered runtime support descriptors. Tests compile C11/C23/C++17 consumers and call native helpers using actual string/Any/Type/view/resizable layouts. Test-only support records follow reviewed bootstrap shapes; production support-descriptor availability remains a producer dependency. Non-C-call exports are omitted and multiple returns fail, following the reviewed refinement.
- **Performance_Report:** complete reviewed entry point/lifecycle with real compiler timings/counters, sorted run records and polymorph summary; missing-report diagnostic tested.
- **Print_Vars:** all eight reviewed declarations with source names, eager single evaluation, type/value columns, configurable indentation/delimiters, empty packs, stdout and caller-location logging.
- **Rewrite:** all nine reviewed declarations for a supported prefix-dereference/edit subset. Actual compiler interception rewrites an original staged target file and executes the result. Sorting, multiline/CRLF composition, preview-only default, stale-file refusal, overlap/invalid-location diagnostics and shutdown are tested.
- **Debug_Info:** canonical CFA/CIE records/opcodes and bounded little-endian DWARF32 integer/LEB128 parsing. Parses actual Clang-produced .eh_frame CIE bytes; all truncated CIE prefixes, signed boundaries and unsupported-expression/overflow failures tested. Other debug parsers are pending.
- **Debug:** macOS/Linux native trace capture/symbolization, exact aliases, native-owned cleanup, debugger presence, kernel-mediated pointer readability, stderr output, abort codes and conditional breakpoints. Actual macOS native/interpreter effects and mmap/mprotect/unmap transitions pass. Linux native branches are source-only; Android/WASM false-presence is target checked. Other debugging paths are pending.
- **Iprof:** real caller-supplied CSV/text report output, reviewed report/row/zone/history shapes and module defaults. Tests CSV escaping, zero-call/manual-zone filters, conditional history storage, row overlay identity and text thresholds. Runtime profiling/instrumentation/history/graphics remain pending; no samples are fabricated.
- **Codex:** canonical public Math alias and source file/module/global-declaration inspection, including real producer code records. Wire metadata/metrics/plugin behavior remain pending precise contracts.
- **Check:** reviewed Windows-only settings/defaults, array predicate, module skipping, manual/message porting checks and callback. Actual compiler messages reject an original small-integer addition; a manual record fixture rejects an array/pointer assignment. Native symbol/elsewhere checks, format checking and finish bookkeeping remain pending.

## Producer and refinement requests

Reviewed refinement resolved the original macro-result enum, compatibility constants, TARGET_OS/literal rules and C-header projection questions. Current implementations follow that refinement; earlier test assumptions are classified in deviations.

Original reproducers under tests/developer-tools/compiler-requests preserve two observations: a TYPECHECKED binary result can have null Type_Info despite typed operands (exit 1), and repeated constant-array .data addresses differ (assertion abort). The latter has no reviewed storage-identity guarantee yet and is an unresolved contract question, not a proven compiler bug. Neither is counted as a passing effect test. Check detects small operands directly and therefore does not require the missing result descriptor.

All sources/tests are durable in this worktree. Source-built jaic, jailint, jaifmt and required NEW native helpers are local. No other checkout binaries were run; shared native config, bootstrap and Extensions are unchanged.
