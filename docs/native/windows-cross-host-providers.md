# Cross-host callback providers

Cross compilation executes compile-time foreign calls in the host compiler process. `tools/windows_cross.py` now prepares the full23 ABI8 SDK/callback profile pairs plus callback context and adaptive probe before target compilation, verifies newly built artifacts against their receipt, and keeps `JAIC_NATIVE_LIBS` separate from target PE `JAIC_CROSS_LIBS`. Existing complete host directories are reused. A missing closure requires an explicit `CARGO_TARGET_DIR` or CI `RUNNER_TEMP`.

Both Linux cross jobs assign the build directory; LLVM23 resource/readobj tools are provisioned separately. Ten selection controls pass. The prior940 immutable48-host-provider inventory was selected with rebuilding forbidden by the test control; no native code executed for that selection. This closes host preparation only. Root must supply the exact failure phase if a missing callback is instead a target PE link dependency; host artifacts are never evidence of Windows runtime or PE provider closure.
