# Private canonical generator access and ownership

The single unparameterized owner is stdlib/internal/developer-tools/generator-session/module.jai. It declares context.generator as *Canonical_Generator.Generator using the default Bindings_Generator import, plus borrowed options and the optional allocation ledger. Configured facades use typed local access and validate the ledger's generator identity/target. This preserves one context field; it does not promise nominal unification among differently parameterized Generator types.

activate(generator:*void, options:*void=null, owner:*Session=null), active_generator()->*void and active_options()->*void remain the shared private access protocol. Canonical maps/records belong only to Generator. Session stores allocation ownership, construction phases and optional exact native parse inputs; it has no cursor/type/name registry or parser model.

Public init_generator and deinit_generator belong to model; run_generator and handle_toplevel_cursors belong to the ASN/run owner after coordinator reassignment; tools owns emission. init installs the supplied pointer, clears the borrowed active-options pointer, and reuses a matching existing ledger as borrowed. Otherwise it creates one heap-backed instance of this SAME Session, marked lifecycle_owned. Public constructors therefore work without importing a private module. An existing failed ledger stays failed. Repeated initialization preserves canonical slot identity and existing generation counters/usage flags.

Primitive initialization delegates actual target layouts/signedness to installed libclang using an embedded, ephemeral C/C++ builtin-type input. It passes configured Clang arguments/include paths and diagnoses malformed argv/NUL/bounds, unsupported OS/CPU and native diagnostics. The probe has no deployed source-header dependency and does not register its cursors in canonical maps. Synthetic int128 probing preserves the user's usage flag. Canonical pointer-to-void slots initially share one pointer object; existing supplied slots are preserved. ObjC ID/Class/SEL/Type are named pointer-sized semantic slots, Block is the reviewed opaque record, string is the two-word Jai descriptor, and the destructor-flags slot initially shares canonical u32. These independently documented placeholder choices do not establish a new native calling ABI.

Caller push_context saves/restores generator/options/session together, including early exits. Native callbacks capture #Context before entry and restore it in their own push_context. Reentrant callbacks reuse the same ledger; another generator gets an ordinary nested context, never a library-managed generator stack.

deinit disposes registered native token sets, then TU, then index, retaining context.generator. It closes only a matching init-owned ledger and clears retained model pointers/cache headers. Caller-owned ledgers stay caller-owned, allowing non-native model consumers until the caller closes them. Native cursors/token views are invalid after disposal. A different active generator is neither restored nor replaced; no registry searches for an inactive allocation owner and no complete aggregate-free/repeated-disposal promise is invented.

The SAME private gm_release_generator_model(generator, owner) handles typed model cleanup for init-owned and tooling-owned sessions. After final consumers/native cleanup, it resets canonical tables, detaches the current owner/options if applicable, closes the ledger through its captured allocator, clears retained model fields and frees the Session itself only when lifecycle_owned. Tools should use this path instead of duplicating cleanup around Session.close. Caller replacement buffers and native library handles remain caller/tooling-owned; retain their external ownership handles and dispose them appropriately before model teardown. Generation counters/usage flags remain with their owning stage.

append_owned registers stable model/header addresses. append_movable_owned tracks buffers without retaining stack/hash-table value header addresses; the typed owner clears cache headers before ledger close. Callback replacement buffers retain their own allocator and are not freed by the ledger. Closing uses the captured allocator even if the ambient allocator changed.

Parse_Input { filename:string; arguments:[]string; overlays:[]Source_Overlay } and Source_Overlay { filename:string; contents:string } are private input/lifetime descriptors. Session.parse_input is borrowed; tools captures exact actual parse arguments/unsaved bytes into the same ledger and keeps them alive through validation. This is not a second model. An arbitrary supplied TU without a receipt cannot yield its original argv through the public C API and must produce an unavailable-input diagnostic.

Tools owns binding_open_evaluation_probe(input,expression)->TU,cursor,available,supported. Model owns gm_evaluate_macro_declaration->Literal,CType,available,supported, which copies supported payloads/types and original location before disposing the temporary TU. Probe cursors/file handles never enter canonical maps. ASN owns public macro state decisions: unavailable preserves pending, evaluated unsupported may discard, and genuine converted expressions may keep.

Regression coverage includes public init->constructor->deinit, nested actual SDK callbacks, repeated-init identity, captured allocator zero balance, borrowed-ledger lifetime, native tokens, SDK target primitives and configured C++/unsigned-char/strict C89 initialization. Exact current receipts and remaining ABI/schema domains are recorded in docs/status/generator-model-shared-audit.json.
