# Generator model implementation

The single canonical Generator, Token_Info and Library_Symbols definitions live in stdlib/Bindings_Generator/generator-state.jai. Public helper signatures live in model-helpers.jai, with one existing module load line. Algorithms and the unparameterized activation/ownership module live under stdlib/internal/developer-tools. No additional parser model, generator registry, canonical map or parameterized Context declaration is introduced.

All 56 assigned names now have callable facade paths (61 reviewed overload signatures). This is not a claim that every C++ specialization, wrapper or vtable branch is finished. The current [remaining-work inventory](status/implementation-remaining.json) distinguishes complete/partial names, committed/draft state, dependencies and verification gaps. [Contract follow-up](specs/questions/generator-model.md) replaces the superseded question table.

Actual canonical construction covers recursive C records, enums, typedefs, variables, functions, callback/pointer/array/qualifier types and expression trees; record/enum type shells preserve canonical identity and can later populate. Reopened namespaces merge native child views in declaration order; a later full lookup expands an earlier types-only pass once, while completed scopes preserve subsequent consumer mutations. Repeated create_function returns null while refreshing the registered record's source metadata. Objective-C interfaces, protocols, categories, selectors and generic type parameters use the same canonical records/cache. Token helpers follow the reviewed leading-star, inside-opener scan and spelling-only equality conventions; macro-literal equality is macro-only. Lookup never allocates a substitute declaration. Bool omission follows NO_ARGUMENT_DEFAULTS and expression presence.

The [single private protocol](generator-session.md) supplies authoritative context.generator and a borrowed active-options pointer, with typed internal accessors. Caller push_context handles nesting; native callbacks restore captured Context. An optional transaction allocation ledger tracks records/strings/copied token buffers and owned array allocation/resizes. Callback replacements keep their caller allocator and are not freed by the transaction. Constructors copy descriptor scalars/nominal references without aliasing mutable child buffers. Canonical maps remain Generator fields; native handles/tokens and map cleanup remain the lifecycle owner's responsibility.

Explicit-input _create_declaration overloads, create_enum(name) and create_empty_struct_type remain caller-owned. Free their copied strings/records once; output_name initially shares each record's immutable name bytes. Stateful constructors return transaction-owned records. Location.file and native token source data borrow the TU. create_empty_struct_type links its Struct.type back to the returned CType; create_enum(name) leaves the underlying width unspecified.

Independent policies where the reviewed contract is less precise: scalar typedef lookup diagnoses cycles and preserves borrowed identity; canonical primitive fields are reused, with missing scalar fields initialized lazily. Function equivalence delegates to the existing limited type comparator; unsupported overload disambiguation retains a collision with a diagnostic. Extra-info pointers borrow the canonical Hash_Table value and must be reacquired after structural cache mutation. Nonpolymorphic metadata uses actual represented alignment/field data; polymorphic/base-record metadata awaits shared vtable construction rather than returning fake completeness. Raw-token literal text is retained in both string_value and raw_value; constructor/destructor output spellings are constructor/destructor. Objective-C output identifiers truncate at the first colon while preserving the foreign selector. Prefix comments use recorded location/newline semantics. Empty token scans avoid requiring a native translation unit; malformed descriptors and out-of-bounds indices remain diagnosed. Common include-guard suffixes are _H, _H_ and _INCLUDED.
