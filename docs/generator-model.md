# Generator model implementation

The single canonical Generator, Token_Info and Library_Symbols definitions live in stdlib/Bindings_Generator/generator-state.jai. Public helper signatures live in model-helpers.jai, with one existing module load line. Algorithms and the unparameterized activation/ownership module live under stdlib/internal/developer-tools. No additional parser model, generator registry, canonical map or parameterized Context declaration is introduced.

All58 currently assigned names have callable facade paths (63 reviewed overload signatures, including the redistributed public lifecycle pair). This is not a claim that every C++ specialization, wrapper or vtable branch is finished. The owned [per-API audit](status/generator-model-shared-audit.json) distinguishes52 complete reviewed host domains from six precisely partial template/SDK/ABI/emission domains, with zero missing bodies. [Contract follow-up](specs/questions/generator-model.md) replaces the superseded question table.

Actual canonical construction covers recursive C records, enums, typedefs, variables, functions, callback/pointer/array/qualifier types and expression trees, including nested/empty record aggregate initializers and aggregate reference defaults; configured/default typedef unwrapping and anonymous record/enum alias promotion, while record/enum type shells preserve canonical identity and can later populate. Reopened namespaces merge native child views in declaration order; a later full lookup expands an earlier types-only pass once, while completed scopes preserve subsequent consumer mutations. Repeated create_function returns null while refreshing the registered record's source metadata. Objective-C interfaces, protocols, categories, selectors and generic type parameters use the same canonical records/cache. Token helpers follow the reviewed leading-star, inside-opener scan and spelling-only equality conventions; macro-literal equality is macro-only. Lookup never allocates a substitute declaration. Standalone function-type construction leaves an absent owning function unconstructed, while later full construction attaches the same canonical parameter records. Only accurate function cursors supply receiver/method/constructor metadata, so returned callbacks do not acquire their enclosing method's flags. Expected unsupported declaration categories return null without poisoning subsequent supported construction; malformed cursors and unsupported expression shapes remain diagnosed. Bool omission follows NO_ARGUMENT_DEFAULTS and expression presence.

The [single private protocol](generator-session.md) supplies authoritative context.generator and a borrowed active-options pointer, with typed internal accessors. Caller push_context handles nesting; native callbacks restore captured Context. An optional transaction allocation ledger tracks records/strings/copied token buffers and owned array allocation/resizes. Callback replacements keep their caller allocator and are not freed by the transaction. Constructors copy descriptor scalars/nominal references without aliasing mutable child buffers. Canonical maps remain Generator fields; native handles/tokens and map cleanup remain the lifecycle owner's responsibility.

Generic C++ class declarations with ordinary type parameters use canonical TemplateTypeParameter records and dependent CType references for fields, pointers, qualifiers and standalone signatures. Supplied elaborated-type child views recover the same parameter or a dependent template application, including recursive class references and report the consumed cursor count. Canonicalization considers native type kind as well as semantic equality, because an unexposed wrapper and its canonical type can compare equal while having different representable shapes. Generic record metadata uses the shared unknown sentinel. Dependent methods with no native mangling remain unprintable functions, while their standalone signatures are available. Ordinary type-only instances use the same primary canonical Struct plus independently owned Type_Reference argument arrays, including nested instances and qualifiers. The supported subset requires the native specialization cursor to share the primary definition's source location; explicit/partial bodies remain rejected. Native size/alignment are retained, including negative incomplete/dependent sentinels when Clang has not instantiated layout. Supplied child views are threaded through pointer, array and function-type recursion; missing dependent views and malformed descriptors are diagnosed. Qualifier copies preserve arguments and comments without sharing mutable argument buffers or Type_Reference nodes. Base declarations are canonicalized by their own native cursor in Generator.declarations_by_cursor, preserving Base(int) and Base(double) as distinct parents even when they share a primary Struct. Template aggregate expressions are currently diagnosed until the printing owner supplies complete instantiated type-name rendering; no argument information is silently discarded. Supported non-type/template-template formals and resolved scalar value arguments are described below; packs remain diagnosed before registration.

Explicit-input _create_declaration overloads, create_enum(name) and create_empty_struct_type remain caller-owned. Free name and output_name separately, together with copied comments and records. Output/source/foreign names have independent writable buffers, including alias promotion and Objective-C selector prefixes. Stateful constructors return transaction-owned records. Location.file and native token source data borrow the TU. create_empty_struct_type links its Struct.type back to the returned CType; create_enum(name) leaves the underlying width unspecified. Raw-token literals likewise retain independent string_value and raw_value buffers.

Type-only record shells already carry native union/anonymous/abstract and declared constructor/destructor category flags. Metadata lookup returns the single unknown sentinel for shells, partially populated scopes and Objective-C records; it never caches incomplete field information. Completed cached metadata can be borrowed through the active Generator without an allocation ledger. Building new metadata requires a live ledger.

Reviewed integration rules are now implemented. Function equivalence requires the same source name and argument count and delegates compared arguments to public is_same_type. It skips only the first argument when requested; return types, output names, calling conventions, defaults and flags do not affect this relation. It therefore inherits the public comparator's limits instead of supplying a stronger private signature relation. Malformed argument storage remains diagnosed. Name-clash lookup conservatively retains collisions outside the shared comparator's supported domain.

The omission visitor tests foreign_name != name for every Function, including ordinary mangled globals. Omitted functions return STOP without invoking either callback. Other declarations invoke the plain callback before the data callback, propagating STOP. Constructor source names are Constructor, CopyConstructor and MoveConstructor; destructor source name is Destructor. Output names apply the first matching configured strip prefix and reserved-name repair, using independent owned buffers. Constructor/destructor strip flags mark those categories omitted.

Canonical scalar conversion maps WChar to the signed slot chosen by native byte width. Float/Double/LongDouble select float32/float64 by actual size; unsupported extended widths, half and member pointers diagnose and return null. BlockPointer uses the one canonical opaque Block record slot with native pointer size/alignment; this does not implement block invocation/capture layout. Signed/unsigned128 types retain native layout, while evaluated wider-than64-bit literal/enum payloads remain diagnosed because the public payload/getter representation is64-bit. Narrow string evaluation copies verified complete UTF-8/empty contents, including parent retry; wide, embedded-NUL and unverified extents remain explicit limits.

Type, non-type and template-template formals are constant canonical declarations. Type/template-template formals use canonical Type; non-type formals use their converted native type. Convertible numeric/reference defaults and simple named type defaults are retained. Default conversion failures reject the current constructor and its invalid canonical dependency closure; retry cannot silently drop a default. A later registered prerequisite can recover construction within the same usable session. Composite/builtin defaults unavailable through the public SDK view remain diagnosed. Packs and full template-template argument identity/arity are not claimed.

Concrete non-type specialization arguments use guarded official SDK cursor argument-kind/value accessors, including resolved defaults omitted from source. Signed/unsigned integral, Boolean and null pointer arguments use ordinary Literal records; a dependent formal integral type can resolve through the instance's corresponding type argument. SDKs lacking class-specialization argument metadata, unrepresentable wider payloads and other unsupported argument kinds diagnose. No token/source-position argument-value inference or second parser is used. Qualified argument arrays and their supported expression/string buffers are copied independently. Canonical declaration/type references remain shared identities.

Derived metadata production is in the independently organized generator-record-metadata.jai and the SINGLE Generator.extra_infos cache. Ordinary records provide real alignment/field information and modified_declarations. Supported Mac64 leaf and single-primary nonvirtual polymorphic records produce ordered vtable entries, typed generated slots, pointer placeholders for omitted slots, a generated Struct in record.metadata, a typed vtable pointer and flattened inherited fields. Official Clang overridden-cursor relationships prove overrides before public equivalence is applied; same-name const/nonconst additions retain distinct slots. Unsupported override comparisons diagnose instead of adding a guessed slot. Generated slot names are index-only identifiers. Cache insertion repairs retained vtable_parent_info links after Hash_Table growth; external cache pointers still need reacquisition after structural mutation.

The bounded metadata ABI domain is supported by [the public Itanium ABI](https://itanium-cxx-abi.github.io/cxx-abi/abi.html) and original Mac C++ runtime/layout oracles at O0/O2, including dispatch order and reused base tail padding. Visible slots currently support ordinary scalar/pointer signatures. Virtual bases, multiple adjustments, virtual destructor slots, covariant adjustments, aggregate/extended/variadic slot calling ABIs and unverified Windows ordering remain diagnosed. Tools emission must consume modified_declarations, generated vtable records and the inherited relationship pointers from this producer; it must not require prepopulation or create another metadata model.

Polymorphic member production also compares byte-aligned native offsets with natural field placement. Extra native gaps become actual owned byte-array padding declarations in modified_declarations; padding_declaration identifies the first such generated member. Bitfield, incomplete, overlapping or incompatible packed polymorphic layouts diagnose. Original aligned-field SDK oracles verify the gap and total size/alignment. Name-clash acceptance validates parameter storage and supported parameter types without incorrectly inspecting an outer function's ignored return type; unsupported nested callback returns still retain a diagnosed collision.

Pending macros invoke ASN-owned check_macro_value when that routine is present in the shared module, then resolve only KEEP. DISCARD is rejected even when omit filtering is bypassed. The shared ASN macro validator and tools native probe now use the model's exact Parse_Input receipt and canonical payload conversion. Missing receipt/environment preserves pending with diagnostics. Actual supplied-receipt lookup exercises validation before the KEEP decision; no duplicate validator/parser or dead probe cursor is introduced.
