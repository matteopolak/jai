# Generator model helpers

Public signatures live in `stdlib/Bindings_Generator/model-helpers.jai`; independently organized private algorithms live in `stdlib/internal/developer-tools/generator-model-helpers.jai`. The reviewed canonical Generator, Token_Info and Library_Symbols now have their single definitions in generator-state.jai. Generator retains #type_info_none and exact public Hash_Table instantiations; cursor hashing/equality delegates to official libclang. The old Windows-only Library_Symbols declaration was moved here, rather than duplicated.

Implementation batches cover explicit model constructors/predicates and identity/name comparisons, then native/stateful integration where canonical dependencies permit. Original public-model fixtures run under interpreter/native O0/O2, formatting and strict lint.

Current coverage: 28 of the 56 assigned names have callable implementations (29 signatures). Of these, 23 names have all assigned overloads implemented under the documented independent policies: `_create_declaration` (both overloads), `count_namespace_refs`, `create_empty_struct_type`, `find_underlying_type`, `get_primitive_or_array_primitive_type_size`, `get_type_alignment`, `is_16byte_integer_type`, `is_assignment_operator`, `is_char_pointer_type`, `is_extern_declaration`, `is_function_type`, `is_incomplete_array`, `is_operator`, `is_operator_name`, `is_pointer_type`, `is_prefix_comment`, `is_struct_field`, `is_target_type_signed`, `is_target_type_unsigned`, `is_targeting_apple_os`, `is_va_list`, `is_valid_identifier_start`, and `is_zero_int_expression`.

Five names remain partial: create_enum has its string overload but needs cursor integration; create_omit_cpp_functions_visitor handles explicit method flags but needs global C++ linkage classification; functions_are_equivalent, contains_equivalent_function and find_name_clash retain the existing type comparator's domain limits. The other 28 names have exact per-overload dependencies/questions recorded in the linked questions table. These counts do not label the full scope complete.

Independent policies: typedef traversal preserves borrowed identity and diagnoses cycles. Scalar classification excludes pointers, arrays, records and functions. Sixteen-byte integers use size16 and integer flags without inventing a width flag. Constructors copy caller strings and return independently allocated public records. Function equivalence compares return/argument types and variadic shape, ignoring source names and non-ABI metadata; optional first-argument skipping applies to both signatures. Name clashes compare effective output names and permit distinct function signatures when overloads are enabled. These policies do not claim unspecified historical equivalence.

Stateful integration questions and remaining variants are tracked in [generator-model questions](specs/questions/generator-model.md). Cursor constructors must share the canonical cursor registry rather than using a temporary isolated parser.

Constructors are caller-owned: free copied name/comment strings once, then their records. output_name initially shares the record's own immutable name bytes. create_empty_struct_type owns its separate Struct and name; Struct.type points back to the returned CType. Location.file remains a borrowed libclang handle, even though copied text survives TU disposal. create_enum(name) intentionally leaves the underlying type unspecified.

Alignment uses explicit_field_alignment, then field_alignment, then the unaliased CType alignment; the second result reports equality with a known natural alignment. Primitive size follows array and typedef/enum edges, returns -1 for nonprimitive/incomplete/unknown types, and diagnoses cycles/overflow. Struct fields are nonstatic, nonmetadata DECLARATION nodes parented by a Struct; the second result returns an anonymous owning Struct when flagged IS_ANON. Prefix comments are nonempty comments except Doxygen postfix markers. va_list recognizes typedef spellings va_list, __builtin_va_list and __gnuc_va_list. Identifier starts are ASCII letters/underscore. Operator detection requires the exact operator prefix followed by a nonidentifier character; assignment detection uses exact C++ assignment operator spellings.

The method-aware omission visitor factory and type-comparison limits are described in the questions document. Unsupported overload comparison conservatively retains a name clash with a diagnostic, avoiding accidental successful emission. The closure uses the existing canonical Cpp_Functions_Visitor_Data record; callbacks are retained as callable values, not copied model state.

Run `python3 tools/check_generator_model.py` with the assigned CARGO_TARGET_DIR after source-building jaic, jailint, jaifmt and the portable/native binding helpers. It checks actual formatting, warnings-denied lint, Windows/Linux x64 source branches, two original new fixtures and two existing independent model regressions in interpreter/native Mac O0/O2. Cross-target source checks do not claim execution. Exact commands/results are retained in CARGO_TARGET_DIR/generator-model-evidence.json. Native cursor construction uses an original unsaved C header and checks copied text after TU disposal. No external object oracle is needed for these explicit model operations; this is not complete native parser/ABI coverage or a combined Mac suite claim.
