# Debug_Info public parser workflows

`parse_dwarf_debug_info` now reads complete little-endian DWARF32 version4 compilation units, abbreviation sets, standard version4 attribute forms and the verified version4 line decoder. `parse_compilation_unit_v4` is the same public unit workflow with its reviewed contextual argument. The result contains types, globals, subprograms, parameters, nested lexical blocks and line sequences; it is not populated by a private-decoder oracle. Names and producer strings borrow section storage. High PC address and constant forms are distinguished. Origin/specification descriptive attributes resolve iteratively; cycles, missing targets, invalid forms and overflow fail transactionally.

Independent policies: the unit offset is the initial-length position in the complete `.debug_info` section; stored DIE offsets and translated unit-relative type references are section absolute. Encoded one-based DWARF file/directory IDs are preserved. Directory zero supplies no prefix. `get_filename` and its file-ID wrapper borrow unchanged paths and allocate joined paths with the active allocator; callers free only joined results. Absolute paths remain unchanged. No path normalization or filesystem lookup occurs.

Supported inputs are DWARF32/version4, 4-byte or 8-byte addresses and line programs representable by the public address-only line model. DWARF64, version5 forms, discontiguous `.debug_ranges` (no input parameter), supplementary sections and nonzero VLIW operation indices fail explicitly. Unrepresented standard attributes are consumed with bounds checks. Type records retain precisely the fields available in the reviewed model; they do not invent member layouts or location-expression evaluations. Cross-unit origin/specification references are unsupported; normal unit-relative type references are translated independently per unit.

`parse_msf` now constructs the canonical public aggregate over the verified MSF7/4096-byte decoder. The header and content borrow the supplied bytes. Stream page arrays, directory page list and independent active/freed FPM arrays use the active allocator. Nil streams are represented by byte_count=-1; empty streams are real empty streams. `get_stream_data` returns an independent allocated copy. `verify_integrity` revalidates the wire graph, compares stream/directory descriptors and verifies current FPM bits against the retained input.

MSF independent read-snapshot policies: growth1, maximum page number u32 max,32768 FPM bits per bitmap page, bitmap count rounded up from file page count, primary/alternate FPM pages1/2, first nonreserved data page3 and user streams starting at5. The freed map has zero bits, representing no deferred frees. `init`, `ensure_room` and `set_all` use represented active-word counts, rover0 and explicit fill bits. Mutations of individual page bits still require caller-initialized bounds; they do not grow silently. Other page sizes and small MSF layouts remain unsupported.

Public arrays have no aggregate deinitializer in the reviewed API. Release nested arrays and bucket storage with their recorded allocator, or retain them in an allocator whose lifetime covers the results. Failed parses release all partial owned arrays and return empty results. Input buffers must remain alive for borrowed strings/header views.

Run `python3 tools/check_debug_info_public.py` after building this checkout's jaic/jailint under the assigned CARGO_TARGET_DIR and `target/jaifmt`. The runner creates original ELF/PDB objects using the official SDK, applies ELF relocations, compares all projected type fields with llvm-dwarfdump and all PDB stream bytes with llvm-pdbutil, and runs public tests on Mac interpreter/native O0/O2. The DWARF tests also exercise multi-unit translation and failed-parse allocation balance. [Evidence](native/debug-info-public-evidence.json) records section hashes and SDK metadata.

The remaining CodeView/PDB and inline-workflow scope is tracked in [precise questions](specs/questions/debug-info-impl.md). Existing private-decoder tests are not counted as completing those public APIs.
