# Canonical incomplete-record printing

The original `bindings-custom.jai:98` failed because the canonical printer required supported layout metadata for every nongeneric record. The model correctly retained `Opaque` with native size/alignment -2/-2 and unknown extra-info, while `Forward` had a real definition, one field and native 4/4 layout. The model/enum constructors and lookup are unchanged by this repair.

The printer now emits a nominal empty Jai record for an incomplete native struct or union only when its existing public `Generator.declarations_by_cursor` association supplies independent proof: a live matching canonical Session/translation unit, an appropriate native cursor kind, no native definition, and official Clang incomplete-layout results. It validates the cursor-table extent and requires matching entries to identify the same canonical cursor. No new record fields, context fields, cache, registry or parser are introduced; native `clang_*` calls delegate to the official library.

The marker supports pointers, not native value storage. Canonical function signatures and ordinary declarations reject incomplete record values through aliases and fixed arrays; a separate type view cannot override its canonical record's unknown layout. Pointer and typedef identities remain printable. Existing type-info directives and their precedence remain honored. Ambiguous manual records, missing cursor evidence, malformed table bounds, explicit alignment, and added fields/parents/virtual slots/overlays keep diagnostics. Complete records continue through canonical `modified_declarations` and real layout metadata. Unknown native size/alignment and extra-info cache contents are never rewritten, and no native padding or layout assertion is invented for an opaque marker.
