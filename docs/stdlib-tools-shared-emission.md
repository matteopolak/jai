# Shared generator emission

The tools owner maintains52 generator emission/parser/printing names and seven
Print_Vars APIs. Canonical model/context/lifecycle remain model-owned. Seven macro
helpers and the runner are ASN-owned. There is one shared session/provider.

All52 completion-inventory names have bodies:43 supported complete and9 partial
in [the exact per-function audit](status/stdlib-tools-shared-audit.json). This is
not full-contract or corpus completion. Partial functions are both integer hex
helpers, print_function, print_struct, print_struct_vtable, print_type_to_builder,
print_literal_to_builder, print_expression_to_builder and
raw_tokens_string_from_cursor. [Questions](specs/questions/stdlib-tools-shared.md)
identify exact unresolved domains; other work continues.

The public C++ bridge consumes canonical declarations and retained Clang cursors.
Native aliases preserve long/long long overload identity. Aggregate output uses
placement construction; reference results preserve storage identity. Constructors,
receiver calls, destructors, defaults and formatting count/data bridges have real
consumers. Its parameters come from represented arguments rather than the Jai
callback. Temporary parameter names are freed; repaired public names retain
session ownership. Per-signature aliases increase generated source size.

Jai wrappers honor three callback modes, copying each returned pointer sequence
before the callback can reuse slice storage. Temporary arrays are freed and
declaration identity preserved. Formatting calls free the actual sprint result.
Checked macro literals use canonical conversion and dispose temporary text.
Failures diagnose and preserve destination bytes rather than committing partial
fragments.
